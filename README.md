# PlayLearn para Linux (apt)

Repositorio apt de [PlayLearn](https://playinglearn.com) para Ubuntu y Debian (amd64).

```sh
curl -fsSL https://novasofttechnologiescorp.github.io/playlearn-apt/instalar.sh | sudo sh
sudo apt install playlearn
```

Las actualizaciones llegan con `sudo apt update && sudo apt upgrade`. Lo publica el workflow `Linux .deb` del repo de la app; no se edita a mano.
